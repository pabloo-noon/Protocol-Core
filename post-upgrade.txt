=====================================================================

and at the latest block, decoded, and compared to the live getter. Slots covered per proxy: EIP-1967
implementation + admin; every sequential variable of the implementation (layouts computed with solc 0.8.28
from the repo build-info); remoteTokens(domain) for all 9 domains; ERC-7201 namespaced storage: ERC20
(_totalSupply, _name, _symbol), Ownable (_owner), Ownable2Step (_pendingOwner), AccessControl
(DEFAULT_ADMIN hasRole for Safe and deployer), Initializable (_initialized/_initializing), Pausable (_paused),
ERC4626 (_asset/_underlyingDecimals, vault only), ReentrancyGuard (_status), and on the LayerZero OApps
OAppCore peers(30101/30165/30378), OptionsType3 enforcedOptions(eid, SEND), OFTCore msgInspector, PreCrime.

Result: 202 decoded-slot-vs-getter and invariant checks PASS, 0 FAIL on all 8 proxies.
  - every raw slot decodes to exactly what the getter returns (no slot shift, no reinterpretation)
  - Initializable: every proxy _initialized = 1 and not initializing; every implementation = uint64.max (disabled)
  - implementation slot = audited impl; rateLimiter byte range of the packed slot = the chain's limiter

checks apply): 30 slot changes, all expected, 0 unexpected:

  - remoteTokens(239) and (50104): old TAC/Sophon token -> 0x…dEaD on ETH USN, ETH sUSN, zkSync USN, zkSync sUSN, Base (and HyperEVM, live)
